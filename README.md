# Wren

邮件，安静一点。Wren 是一个独立开发的邮件客户端，支持 Mac、Windows、iPhone 和 Android。

- 官网：https://0x2cc.github.io/wren/
- 想要的功能、使用中的想法：到 [Discussions](https://github.com/0x2cc/wren/discussions) 聊
- 遇到问题：[提交 Issue](https://github.com/0x2cc/wren/issues/new/choose)

这个仓库放的是 Wren 的官网和用户反馈。App 的源代码不在这里。

## 反馈时请注意

不要贴邮箱授权码、密码、API Key，也不要贴别人的邮件内容和邮箱地址。截图前请把这些信息遮住。
